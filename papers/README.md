# Papiers

Les PDF ne sont pas versionnés : certains ne sont pas redistribuables (licence arXiv par défaut)
et ils sont tous librement disponibles sur arXiv.

Pour les récupérer :
```
uv run python scripts/download_papers.py
```

La liste fait foi dans `papers.toml`. Pour ajouter un papier, y ajouter un bloc `[[paper]]`
puis relancer le script.
